## Publish with Cloudflare Pages

1. Create a new GitHub repository and upload `index.html` and `styles.css`.
2. In Cloudflare, open **Workers & Pages** and create a Pages application.
3. Connect the GitHub repository.
4. Choose a static site / no-framework setup. No build command is required.
5. Set the output directory to the repository root if Cloudflare asks for one.
6. Deploy. Cloudflare will give you a public `*.pages.dev` URL.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and `styles.css`.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.
5. GitHub will publish a public URL for the site.
